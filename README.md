# bowen-hub

Kevin 的每日新闻、A 股复盘和论文阅读产品。电脑版已上线，手机开发暂停。

- **美股新闻室**：中文早报每天 07:10 开始、08:00 前完成；盘前简报在美股交易日开盘前生成；周报随周一早报发送。时间以新加坡/北京时间为准，盘前按实际美股交易日与夏令时换算。
- **A 股观测台**：每个 A 股交易日收盘后自动更新的复盘网站 → https://bowen-market-observatory.pages.dev/
- **论文阅读馆**：知识宇宙分类、中文导读、带页码的原文与表格证据 → https://bowen-paper-library.pages.dev/
- **私人控制台**：今日、新闻室、论文、事件日历，通行密钥登录 → https://bowen-console.pages.dev/
- **MCP 服务**：授权客户端可查询新闻、复盘和论文；即时论文问答当前等待普通 API 额度恢复。

截至 2026-10-08，正式任务 **29/31** 已合并；两公开站于 10/7 切换到新系统。剩余整体验收、真实 14 天观察及确认后停旧，见 [交付进度](docs/progress/delivery-status.md) 和 [验收清单](docs/progress/T52.md)。

## 日常怎么用

1. **看新闻**：邮箱按正常调度收到早报和交易日盘前，周一收到周报。控制台“新闻室”可回看版次、来源和行情。早报覆盖全部活跃自选股；名单由 `config/us_watchlist.yaml` 维护。验收期间保留已发送版次，不手动强制重跑。
2. **看 A 股**：交易日打开观测台，先读当天结论、成交额、涨跌停和表盘，再看正文、风险与下一交易日。17:05 起更新、21:00 为完成截止；休市显示上一交易日，不生成虚假的当天数据。
3. **找论文**：Kevin 于 10/8 确认范围 B，公开阅读馆已展示全部 88 份可读版本、87 项研究；首页按大类、小类进入，也可搜索或切换列表。同一研究的版本在单篇切换，私人笔记与掌握状态仍需控制台登录。阅读页保留原文页码、表格截图、固定目录和导出。
4. **上传论文**：在私人控制台论文页上传 PDF 或提交 arXiv 链接，查看入库状态与草稿，审阅后再决定是否公开。真实“上传到草稿 ≤30 分钟”的线上闭环仍待验收，公开范围按本人标记维护。
5. **看日程与管理账户**：事件日历显示 A 股事项、公司财报与美国宏观日期，长跨度或月精度事项在“本月持续事项”。月历只读；右上角账户菜单管理通行密钥、已授权应用及退出，不再设置独立设置/运维/自选股页。
6. **在 Claude 里查询**：添加自定义连接器 `https://bowen-console.pages.dev/mcp`，在正式控制台完成 OAuth 授权。新闻、复盘和论文查询可用；带页码即时问答需要普通 OpenAI API 额度，Kevin 尚未决定充值，不把月费套餐当作 Worker 问答额度。

Cloudflare 在现有 API Worker 内每 10 分钟检查，到点缺产出才触发 GitHub；原 GitHub 定时作备用，运行中或已完成日期不重复。云端记录观察结果，有新失败才通知。Mac 上 23:15 的应用检查只是辅助，需要 Mac 唤醒和应用运行。

实际观察从 UTC 2026-10-07 00:18:19 开始；最早新加坡 10/21 08:18:19 满 14 天，届时核对实际结果再交停旧清单。旧系统与旧成功部署现在保留。日常使用耗时记录在 [五交易日验收表](docs/progress/daily-use-acceptance.md)，SMTP 接收不代替本人收件确认。

## 架构一句话

契约驱动的多语言单仓：TypeScript 负责网站、API 与 MCP，Python 负责行情、新闻、论文和评测，两边通过契约生成的类型交流；AI 统一经过能力运行时。采用现有 Cloudflare 免费服务和公开仓库标准 runner；实际历史账单仍需账户权限核对，免费选型不代表旧费用已清零。详见 [架构](docs/01-架构与技术栈.md)。

## 维护时从哪里继续

- 先读 `AGENTS.md`、总览、架构、协同协议及最新 `docs/progress/`，沿用实际断点；不用从 T00 重建已完成产品。
- 每个任务使用独立 worktree，本机检查完成后推送；契约单独提交，不手改生成物。真实评测只在需要时本机执行，不随手派发 CI 或早报。
- G3 已获本人确认且实际完成；G4 仍需真实观察通过后 Kevin 再确认。旧代码不读不改，迁移只读旧数据；写业务数据只经 API。
- 日历、新闻与调度的实际结果见 [每日运行](docs/progress/daily-operation.md)、[收尾观察](docs/progress/final-observation.md)。密钥通过已配置的环境/云端密钥管理，值不进日志或仓库。
