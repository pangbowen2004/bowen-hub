# bowen-hub

Kevin 的全部个人产品，从零重写，放在一个仓库里：

- **美股新闻室**：以美股和自选股为中心的中文简报——早报（每天 07:30 前）、盘前简报（美股开盘前 45 分钟）、周报（周六上午）。
- **A 股观测台**：每个 A 股交易日收盘后自动更新的复盘网站 → https://bowen-market-observatory.pages.dev/
- **论文阅读馆**：中文导读 + 带页码的原文证据 + 概念图谱 → https://bowen-paper-library.pages.dev/
- **控制台**：Kevin 的私人后台（新闻归档、自选股、论文阅读与问答、上传新论文、运维），通行密钥登录。
- **MCP 服务**：在 Claude、ChatGPT 里直接查新闻、查复盘、问论文。

现在这个文件夹里**只有文档，还没有代码**。代码由多个 AI Agent 按 `tasks/graph.yaml` 并行开发。

## 架构一句话

契约驱动的多语言单仓：TypeScript 负责对外服务（网站、API、MCP），Python 负责计算（行情、新闻、论文、评测），两边只通过契约生成的类型交流；AI 是可配置、可评测、可换模型的能力。全部跑在 Cloudflare 和 GitHub 的免费额度里，只有 AI 按量付费。详见 `docs/01`。

## 怎么开工

1. 先准备账号和密钥（Agent 做不了）：`docs/07-实施计划与验收.md` 第 2 节。
2. 在这个文件夹里打开你最强的 Agent（Claude Code、Codex 等），发下面这段话，让它当“编排者”：

   > 读 AGENTS.md、docs/00、docs/01、docs/11 和 tasks/README.md。你是编排者：按 tasks/graph.yaml 从 T00 开始，把可以并行的任务分给工作者 Agent（每个任务一个 worktree），审查并合并，每完成一个波次向我汇报一次。遇到文档没写清楚的地方，汇总后一次问我。

3. 你只需要在 5 个关卡出现（`docs/07` 第 3 节）：G0 准备账号 → G1 看预览的样子 → G2 验收 → G3 确认上线 → G4 停老系统。

## 日常怎么用（上线后由 Agent 补全）

- **看新闻**：什么都不用做，邮箱按时收到三个版次；想回看、搜索、给某期打分，打开控制台。
- **看复盘**：什么都不用做，交易日晚上 9 点前网站自动更新。
- **读论文**：控制台上传 PDF（或贴 arXiv 链接），半小时内出现导读草稿；读过没问题点“公开”，公开站几分钟后自动更新。
- **在 Claude 里用**：添加自定义连接器 `https://bowen-console.pages.dev/mcp`，用通行密钥登录一次即可。
