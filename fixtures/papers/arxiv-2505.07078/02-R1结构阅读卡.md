# R1 结构阅读卡

## 先用通俗语言讲清楚

- 这篇论文想解决：短时间、少量明星股票上的 LLM 交易结果，是否能代表长期真实能力。
- 以前的问题在于：股票池与时间窗口选择性强，可能混入幸存者、前视与数据窥探偏差，且基线偏弱。
- 作者的做法是：建立 FINSABER，把历史成分股、含退市标的的选股和多类择时策略放进 2004–2024 的滚动评估。
- 最重要的发现是：LLM Agent 在扩大的评估中没有稳定风险调整优势；部分绝对收益亮点伴随较低 Sharpe 或较大回撤。
- 对我们的意义是：可靠 Agent 系统不能只保证任务跑完，还要把评估窗口、可用信息、基线、成本和版本固化为可审计运行时契约。

## 0. 阅读隔离与材料层级

- 先读原始 PDF 的方法、结果、表格与附录并冻结最低结论，再读讨论/结论，最后才读取 `QuantML导读.md`。
- 原文为一手证据；QuantML 导读只提供中文解释和“扩大股票池/窗口”的复现线索，不用于补造原文事实。
- 冻结的最低结论：**在论文实现与评估期内，扩大窗口和股票范围后，所测 LLM 策略没有呈现一致的风险调整优势；这不能外推为所有 LLM 交易方法永远无效。**

## 2. 研究设计

- 数据或样本：价格、新闻、申报文件等；四种选股方式在历史 S&P 500 成分范围内得到 91/84/63/80 个不同股票；主跨度为 2004–2024。
- 纳入与排除：使用历史成分列表并纳入退市标的；个别数据源起点导致各股票可用期不同。
- 核心变量、干预或输入：随机、动量、低波动、FinCon 选股；规则、ARIMA/XGBoost、A2C/PPO/SAC/TD3、FinMem/FinAgent 择时。
- 比较对象或基线：Buy-and-Hold、技术规则、预测模型和 RL 策略。
- 主要结局或评价指标：年化/累计收益、波动率、最大回撤、Sharpe、Sortino、CAPM alpha、费用与换手。
- 分析方法：选择性短窗复现、四股票长期扩展、组合滚动评估、配对 t 检验、CAPM 回归、市场状态分组。
- 研究流程：先选股，再对每个标的独立运行择时策略；选定窗口内训练/评估并滚动推进。Appendix B 说明四股票设置为 2 年窗口/1 年步长、最多 3 年训练，复合设置为 1 年窗口/步长、最多 2 年训练。

## 5. 作者结论与明显边界

- `[作者主张]`：既有 LLM 投资能力证据受窄范围、短时段与偏差影响；FINSABER 下 LLM 方法未稳定优于传统基线。
- `[直接证据]`：Tables 3–6 和 Figure 2 中的长期、复合与分状态结果。
- 作者承认的限制：规则策略未逐一调优；不能完全消除 LLM 预训练造成的前视信息；只用公开数据。
- 我们在 R1 阶段发现的明显限制：结果按单标的汇总而非真正多资产组合；配对 t 检验可能忽略时间依赖；Agent 复实现与模型版本影响可复现性；费用、提示词与数据抓取仍需代码级核查。
- 暂时不能下的更强结论：不能说“LLM 的 alpha 全是幻觉”、所有市场/Agent 都失败，或不显著 alpha 证明市场有效。

## 6. 与我们的研究有什么关系

- 可直接使用的观点或证据：评测时间范围、对象范围、历史可得性和强基线可以逆转 Agent 能力判断。
- 可借鉴的方法、数据或指标：历史快照、滚动训练/评估、含退市对象、regime 切片、成本台账、统计显著性层。
- 对当前假设的支持、反驳或限定：支持“可靠运行时必须治理评测过程”；限定“任务完成率/单一收益足以代表长期科研 Agent 质量”。
- 与已读论文的关系：为 HarnessBench/HarnessOpt 的运行时可靠性增加一个领域实证层；为 AutoResearchLab 提供防止实验选择性报告的例子。
- 未来可能用于：研究设计、相关工作、评测协议、讨论与最小复现。

## 7. 是否升级

- 是否建议进入 R2：是（若作为课题核心证据）。
- 升级理由：结论重要，但统计单位、时间依赖、实现保真、费用和组合口径可能改变证据强度。
- R2 应重点审计：Tables 4–6 数值回算；滚动窗口泄漏；配对单位与多重比较；模型/提示词/数据版本；按股票平均与可交易组合差异。
- 是否值得做 R3 可行性评估：值得；先以一种选股×B&H/FinAgent 的最小切片验证，不必复现全套。
