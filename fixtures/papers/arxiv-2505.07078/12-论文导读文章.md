# FINSABER：把 LLM 交易策略从漂亮短窗拉回长期现实

> 一句话：FINSABER 用 2004–2024 的长时间跨度、历史成分股、退市样本、强传统基线和成本台账重新评估 LLM 交易 Agent，发现偶尔的高收益没有形成稳定风险调整优势，说明评测窗口本身足以制造“智能交易”的幻觉。

## 先说结论

FINSABER 不是又提出一个更会交易的 Agent，而是在质问此前的结论是否站得住。很多 LLM 量化论文只选几只明星股票和一段强趋势行情，展示最终财富曲线，却没有历史成分变化、退市标的、风险指标、统计检验或 API 成本。这样的评测很容易把“选中了好时期”误写成“模型有能力”。

作者把观察窗口扩到 2004–2024，并把投资拆成选股和择时，在相同框架下比较规则、统计/机器学习、强化学习与 LLM Agent。结果是：LLM 方法有时获得较高绝对收益，但长期 Sharpe、CAPM alpha 和不同市场状态下的表现并不稳定。最重要的贡献因此不是某个排行榜名次，而是一套让乐观故事经受时间、样本和基线压力的评测框架。

## 论文为什么要做这件事

如果只看 NVDA、TSLA 等长期大涨股票，且时间窗恰好覆盖牛市，买入并持有本身就很强。Agent 只要维持较高风险敞口，也可能获得漂亮收益。若数据只包含今天仍在指数里的公司，还会产生幸存者偏差；若只报累计收益，又会掩盖回撤、换手和市场 beta。

FINSABER 认为，“LLM 是否会投资”必须拆成几个可核查问题：它能否在当时可见的信息上选股？能否择时？高收益是否只是承担更多系统性风险？在牛、熊、震荡市场中是否都成立？运行成本是否抵消收益？

## 核心方法到底怎么运转

框架首先重建历史时点的股票集合，包括历史指数成分和退市标的，避免拿今天的幸存者回看过去。然后把策略分成选股和择时两层：股票集合可由随机、动量、低波动或 FinCon 等方法产生，择时层再比较 buy-and-hold、规则、ML/RL 与 FinAgent、FinMem 等 LLM Agent。

评价不只看年化收益，还同时报告波动、Sharpe、回撤、配对检验、CAPM alpha、市场状态切片以及 API/数据成本。这里的核心思想是：同一条高收益曲线必须通过多个互相补充的检查，才有资格被解释成稳定能力。

## 实验怎样检验这个方法

论文的主跨度为 2004–2024。作者先把四只热门股票上的短窗结果拉长，再在历史成分股上构造多类股票池和择时策略，并用牛市、熊市、震荡状态切片检查防守性。

| 证据 | 数字 | 含义 |
|---|---:|---|
| 动量设置 FinAgent 年化收益 | 13.950% | 绝对收益高 |
| 同一设置 FinAgent Sharpe | 0.104 | 风险调整后并不强 |
| 已报告 LLM CAPM alpha | p > 0.34 | 没有显著 alpha 证据 |
| 复合实验 LLM 成本 | 约 700 美元 | 评测成本不能忽略 |

## 结果说明了什么

首先，时间窗会改变故事。四只明星股票扩展到各自可用起点至 2024 后，只有 TSLA 保留较清楚的 LLM 相对优势，其他标的被 buy-and-hold 或简单方法匹配、超过。这不能代表整个市场，却足以推翻“短窗胜利可以自然外推”的想法。（论文 p.5，Table 3）

其次，高收益不等于 alpha。动量设置中 FinAgent 年化收益 13.950% 为该块最高，但 Sharpe 只有 0.104；论文报告的 LLM CAPM alpha 的 p 值都大于 0.34。正确结论是“尚无稳定风险调整优势”，而不是“已经证明 alpha 为零”。（论文 pp.6–7，Tables 4、6）

市场状态分析也没有显示 LLM 在熊市更可靠。Buy-and-hold 在牛/震荡/熊市的 Sharpe 为 0.61/0.48/−0.28，FinAgent 为 0.12/0.19/−0.38，FinMem 为 −0.19/−0.10/−0.97。LLM Agent 没有表现出稳定防守，但 regime 的年度阈值定义和年份数量也限制了结论。（论文 p.8，Figure 2）

最后，FinAgent 示例成本为 198.24 美元，FinMem 为 31.79 美元，复合实验总 LLM 成本约 700 美元且不含 embeddings。对研究系统而言，调用成本、模型版本和缓存规则都必须进入复现台账。（论文 pp.14–15，Appendix G）

## 这篇论文哪里最强，哪里最危险

最强之处是它把数据可得性、幸存者偏差、强基线、风险和运行成本放到同一评测中，并主动用长时间跨度挑战已有的乐观结论。这种工作对科研基础设施很重要，因为它改变了“什么算证据”。

危险之处是反向过度解读。四只明星股不是完整横截面；不显著的 alpha 不是零 alpha 的证明；Agent 实现、模型版本和统计单位也可能改变结果。因此不能从本文推出“所有 LLM 投资都无效”。


## 代码从哪里读

官方仓库是 [waylonli/FINSABER](https://github.com/waylonli/FINSABER)。当前 `main` 已升级为 FINSABER-2；要复现这篇 FINSABER-1，必须使用官方指定的 [reproduce 分支](https://github.com/waylonli/FINSABER/tree/reproduce)。当前回测包在 [finsaber](https://github.com/waylonli/FINSABER/tree/main/finsaber)，最小自定义数据示例在 [custom_dataset_example.py](https://github.com/waylonli/FINSABER/blob/main/examples/custom_dataset_example.py)，但不能把新主分支结果冒充原论文复现。

## 读完后记住这三件事

- 先扩大时间和股票池，再谈 LLM 是否跑赢市场。
- 高收益、Sharpe、alpha、regime 和成本回答的是不同问题，不能只挑一个。
- 结论是否成立高度依赖时间窗、股票池、基线、成本和统计检验，不能事后挑选评测口径。
