# T10 HTTP 回放

`*-edge` 是明确合成的离线边界输入，只用于解析/故障测试，不是市场新闻或完整交易日录制。

`recorded-2026-09-30/` 由根在 2026-10-01 UTC 真实执行来源检查录制：142 个 HTTP 响应加 manifest，共 143 文件。查询以美东 2026-09-30 为新闻/公告窗口，日线读取当日和前一日；日程检查随后七天；RSS 仅当前返回的前 N 条，不能冒充历史全日覆盖。公开响应保留原文以支持事实解析，不保存请求头、key/token 查询、错误正文或账户接口。

29 个启用来源中 22 个检查成功。CNBC HTTP403、Venturebeat HTTP429、36kr HTML 安全检测均如实失败；Nasdaq、财政部 ReadTimeout 没有产生响应，因此严格回放报覆盖缺口；Finnhub/FRED 缺 key，不伪造响应。manifest 保留当时真实健康结果。36kr 返回安全检测 HTML，不是 RSS 格式变体，不绕过检测或替换来源。

离线集成验收用全量录制按公开请求精确回放，并消耗全部响应，验证所有 29 个来源最终状态；两个真实超时源在回放中明确为未录请求。根负责最终真实凭据匹配扫描，不在日志展示值。
