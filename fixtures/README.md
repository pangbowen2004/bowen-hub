# fixtures —— 老系统的真实输出（只读）

这些文件是从老项目原样复制来的**数据**，不是代码。用途：
1. 新实现的对照答案（尤其是市场观测台 2026-08-28 的全量计算）；
2. 单元测试和迁移脚本的测试数据；
3. 看老产品输出长什么样。

不要修改这里的老数据文件。老格式的字段名和新格式不同，对照时按 `docs/03`、`docs/06` 的说明做映射。

开发过程中会新增三个子目录（各归一个任务，见 `tasks/graph.yaml`）：

| 目录 | 内容 | 负责任务 |
|---|---|---|
| `samples/` | 由老数据转换的**新格式**样例（通过契约的 JSON Schema 校验），测试和前端开发用 | T01 |
| `http/news/` | 美股与新闻数据源的录制回放数据（测试离线运行） | T10 |
| `tushare/` | 2026-08-27、08-28 两天计算所需的 TuShare 原始数据（parquet），M-1 离线对照用 | T20 |
