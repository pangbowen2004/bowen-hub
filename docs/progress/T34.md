# T34 控制台论文页面

## 交付
`/papers` 提供完整分页后的搜索、研究空间/公开/审核/深度/年份/类型筛选、排序和批量公开。`/papers/$id` 读取完整论文、私人笔记与解释卡，展示导读、学习材料、证据页码、审核、相关论文、阅读设置和原始 Markdown 导出。`/papers/inbox` 支持 PDF/arXiv、失败重试、处理状态和终态刷新；`/papers/graph` 使用实际图谱数据。

问答使用生成客户端与真实流协议：须收到完整终态、合法 generatedBy 和页码才允许保存解释卡，失败回答不可保存。原文页通过 API 读取 PNG，在对话框打开并回收 Blob URL。笔记自动保存串行执行，刷新同篇时只更新干净编辑器；保存过程中与未提交编辑不会被远端旧值覆盖。公开操作不抹掉尚未保存的阅读设置。

样例模式明确标注“样例数据 · 操作仅用于页面预览”，操作只保存在当前会话；演示不会冒充实际模型、入库或部署成功。正式模式不使用这些处理器。
