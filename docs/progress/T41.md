## 交付

**`/mcp`（`services/api/src/modules/mcp/`、`services/api/src/lib/auth/mcp-access.ts`）**
- 官方 SDK `@modelcontextprotocol/server` 2.2.0 的 `createMcpHandler`：同时服务新版协议（2026-07-28）和旧版握手（无状态，每个请求一个新服务实例；GET 流与 DELETE 会话返回 405）。服务名 `research-console`，带一段给模型看的使用说明（改自选股先确认、新增资料要问全、问答会产生费用、没有买卖建议）。
- OAuth 保护：令牌是 Better Auth 签发的自包含 JWT，公钥直接从本实例读（不走公网回环请求），校验签名、签发者、受众（`<AUTH_BASE_URL>/mcp`）、过期、`typ=at+jwt`、`mcp` 范围，拒绝绑定发送者（DPoP）的令牌；然后再核对固定使用者（`sub=owner`）和**当前有效授权**：授权记录存在且含 `mcp`、客户端未停用、令牌签发时间不早于这条授权的建立时间。原因：JWT 没有数据库行，T40 设置页“撤销授权”删的是授权记录并撤销刷新令牌，已签发未过期的 JWT 仍然签名有效，不逐次核对就撤销不掉；“签发时间不早于授权建立时间”让撤销后重新授权也不会让旧令牌复活。取公钥失败是服务端故障，原样 500，不冒充 401。
- 401/403 挑战带 `resource_metadata`（指向同源 `/.well-known/oauth-protected-resource/mcp`）与 `scope="mcp"`；带 `Origin` 的请求必须来自控制台自己的来源（防 DNS 重绑定与跨站），命令行和服务端客户端不带 Origin，照常放行。
- 12 个工具来自各模块已有的 `mcp.ts`，`registry.ts` 汇总并只开放 docs/09 第 6 节列出的这 12 个（顺序一致）；`adapter.ts` 把结果序列化成 JSON 文本、业务错误和参数错误作为 `isError` 工具结果返回（不是协议错误）、未知异常只给通用提示且日志不含异常正文。八个查询工具标 `readOnlyHint`，自选股新增/删除标 `destructiveHint`，问答与提交论文标 `openWorldHint`（Inspector 里分别显示 READ-ONLY 与警告图标）。不另写业务逻辑。
- `papers_ask` 经 `/mcp` 调用时，入口先核对令牌，再把原始请求转交同一个 Worker 导出的 SQLite Durable Object 执行（每次一个对象、内部标记头防再次转交），与 HTTP 问答接口同样的做法（新增 `docs/adr/ADR-0015-MCP的论文问答同样在Durable-Object中运行.md`）。原因：问答在普通免费 Worker 里实测 CPU 超限（ADR-0014），`/mcp` 原本没有走这条路。

## 与文档不一致或没做完的

- **问答的真实调用没有验证**：`papers_ask` 用离线模型夹具验证了接线（含经 Durable Object 执行）；真实问答与对象内 CPU 待 API 额度恢复，随 P-11 由 T52 实测。线上 `/mcp` 其他工具的 CPU 也没有真实部署测量（Workers 测试环境里每个请求中位数约 1 ms、最慢约 2 ms，含令牌核对、一次 D1 读取和 SDK 处理），部署后由 T52 一并记录。
- **只有新闻来源有健康接口**：docs/05 写“数据源健康”，契约里只有 `GET /v1/news/sources`，A 股 TuShare 等没有对应记录，页面只能显示新闻来源。
- **用量里没有“后端”字段**：`AiCall` 契约没有区分套餐与 API 的字段（套餐调用只是费用为 0、模型名不变），页面无法逐条标注后端，只能在说明里写明并照实显示 token。要标注需要改契约（增量可选字段）。
- **不支持不带 `resource` 参数的旧客户端**：授权时没有 `resource`（RFC 8707）的客户端拿到的是不透明令牌，`/mcp` 返回 401 与挑战（有测试固定这一行为）。MCP 授权规范要求客户端带 `resource`，官方 Inspector 与 SDK 都带。
- **不支持浏览器页面直接连 `/mcp`**：带 `Origin` 且不是控制台来源的请求一律 403，没有 CORS；官方 Inspector 的网页是经它自己的本机服务端转发，不受影响。
- `markets_day` 返回完整的 `MarketDay`（约 130 KB），而 docs/09 第 6 节写的是“摘要 + 关键指标”；这是 T23 已合并的工具实现，T41 只汇总不改，对模型上下文很重，建议编排者考虑转给 T23 瘦身。`papers_get` 同理返回整篇 `Paper`。
- Inspector 网页在撤销授权后重发请求会一直显示 PENDING（其 SDK 在刷新令牌也失败后等待重新授权，不报错），所以“被拒”的证据用直接请求（401 与挑战）和官方命令行（`auth_required`）给出，没有断言网页上的表现。
- 编排者需要在 `docs/01` 第 10 节的 ADR 索引补一行 ADR-0015（规格文档只由编排者修改）。
