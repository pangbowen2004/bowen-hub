## 交付

- 首页、单篇、2D 图谱、3D 宇宙、三研究空间、关于页共 8 个 HTML 路由；另有单篇 `.md` 和 `/llms.txt`。首屏 HTML 包含完整卡片和阅读正文。
- 首页使用 MiniSearch 7.2.0 构建浏览器本地索引，覆盖中文/英文标题、作者、一句话、概念和空间；Intl.Segmenter 分词，多查询词 AND 与前缀匹配，避免“的”等单词造成无关 OR 命中。空间/年份/论文类型/阅读深度筛选和最近更新/年份排序保留；类型选项使用中文标签。
- 单篇包含标题、作者与资源、30 秒速览、术语、Markdown 导读、可按类型筛选的 claims、默认折叠的自测/主动回忆、技术附录和批判预审、引文与相关论文。缺省内容不补造空模板。覆盖率只表示阅读覆盖，不表示质量。
- 共享 React PaperReader 实现整套正文，公开站仅 SSR、不 hydration；安全解析后的 `ReadingParagraph[]` 由宿主传入。T34 可以复用正文、主张过滤、证据浮层、自测和附录，宿主仍须安全解析 Markdown。阅读覆盖公式由共享组件导出，静态宿主与控制台无需分别实现。
- 证据原生 popover 展示主张、指标、条件、已有摘录/定位/页码与边界；推断另标“解释性推断”，旧材料缺失摘录/页码不伪造。Astro EvidenceMark 也提供同样展示格式。
- sigma 3.0.3 + graphology 0.26.0：明确关系/概念共现两视图、搜索高亮、图例、节点打开论文、窗口适配和主题令牌；没有因为共享概念而添加论文关系边。
- 3d-force-graph 1.80.1 仅宇宙页点击按钮后动态加载；可旋转、缩放、点击论文；有加载/失败提示、手机 2D 入口、减少动态效果设置、卸载清理及主题适配。不会在普通阅读页加载该库。
- 公开路径仅来自公开 catalog，详情 visibility 再校验，图谱与相关论文过滤公开论文 ID；私人笔记、解释卡、legacyCards、私有 PDF 不参与构建。Markdown 导出正文和证据表，保留原文定位；llms 提供所有公开论文的绝对 Markdown 地址。浏览器不读取 API。

## 根审查修正

1. 跨论文结构卡的 k1/k2 是局部 ID。相关论文现在按公开派生图 `discusses` 的规范概念目标集合匹配；局部 ID 相同但概念不同不匹配，别名归并后的相同图谱目标可以匹配。图谱边不被修改。
2. 与 T30 `paragraphs` 一致：围栏状态感知，剔除围栏外真正 ATX 标题行后空行划段；Astro Markdown AST 保留独立标题和完整围栏。无空行被标题打断的正文片段共享对应段落证据索引，代码中的伪标题不被剔除。
3. 补接既定 MiniSearch；没有用字符串 contains 代替全文索引。
4. 原文主页/代码资源统一只允许绝对 `http:` / `https:` URL；无效值不提供链接，无效 landingPage 可回退有效 sourceUrl。新增两项回归覆盖 javascript（含大小写/换行）、data、file、ftp、协议相对地址和畸形值，以及安全回退。
5. P-5 新增真实画布节点点击：从实际绘制的 PNG 识别公开样例论文节点位置，Playwright 鼠标移动/点击，分别断言 2D 和 3D 跳转 URL 与论文标题。3D 等待真实 raycaster 悬停标签出现后点击，不调用组件回调、不模拟渲染器。第一次完整运行 37 通过、2 个 3D 点击失败，原因是悬停更新帧尚未完成；等待真实悬停状态后，三视口定向 3 项和完整 39 项均通过。
6. 真实手机验收曾发现画布网格最小宽度、正文 Markdown 表格最小宽度造成溢出，已限制领域容器及正文表格；保留证据/实验宽表内部横向滚动。
