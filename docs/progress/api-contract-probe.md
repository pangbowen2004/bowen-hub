# 空库契约探测修正

资源接口实际接线后，临时空库中不存在的期次会返回404。旧探测脚本无条件拒绝404，导致Schemathesis在首次接口扫描阶段停止。现在只接受OpenAPI登记的错误响应、application/problem+json与生成Problem验证通过的404；未挂载路由、鉴权失败和内部错误仍阻断。新增纯函数明确验证Problem.status=404，并拒绝Hono未挂载路由的固定“接口不存在”响应；三个回归测试执行实际Hono路由并覆盖资源404、无登记、状态/媒体类型不符及坏JSON。独立审查指出初版仅校验Problem会放行缺路由，现已修复且复核通过。

setup/check/test均退出0（TS671、Python176）。使用修正脚本在T14实现上扫描全部23个接口，并生成422个模糊用例，全部通过；第一轮还实际发现NUL搜索词500，业务修复后同种子复测通过。三个模糊测试警告分别为空库缺数据、服务令牌不允许私有写、路径与正文ID一致性；T14正常状态Workers测试另行覆盖，不将警告当成功写入证明。
