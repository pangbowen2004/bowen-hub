状态：实现和本机验收完成，独立审查问题已修复；等待 PR CI 与 squash 合并（2026-10-01）。

## 交付

TypeSpec 是字段及接口的唯一定义：平台、自选股、新闻、市场、论文及所有能力输入输出齐全。docs/08 的 80 个接口逐项覆盖，每个接口都有正确的 x-task，34 个 JSON GET 均登记默认样例。论文问答使用 text/event-stream；文件媒体类型区分 HTML、PDF、PNG。

生成链输出 OpenAPI 3.1、JSON Schema、TypeScript 类型/Zod/fetch/TanStack Query/MSW，以及 Pydantic v2。生成目录均由 mise run gen 生成，未手改。T02 路由生成脚本尚未提供，生成链保留调用入口并明确跳过。

样例含 2026-08-27/28 MarketDay、日摘要、61 条假设、79 条事件、指数历史、周报/摘要/参考配置；两篇 Paper 与私人内容、目录、图谱、搜索、审查和上传；legacy 与手写早报 Edition、自选股、运行/调用/评测记录。原始 fixtures 只读；迁移缺失值、合成部分、允许丢弃字段与私人补充卡逐项记录在各 samples/README.md。

提示词渲染共享向量覆盖空值、数字、中文、JSON、布尔及空对象；顶层空对象和缺字段显示“（无）”，嵌套空对象保留 JSON。后续 T04 两端直接复用。

## 独立审查与修复

新闻、平台和生成链由独立 GPT-6.1 Sol medium 审查；市场和论文分别由另一位同模型 Agent 审查。编排者核对了证据并修复：

- Orval 冗余 Zod Output 类型别名与能力模型重名；仅删除固定推导别名，保留模型 schema。
- 生成的客户端和 hooks 原样发送 HTML 字符串及 PDF/PNG Blob，JSON 仍编码；真实生成函数 mock fetch 回归覆盖正文和媒体类型。
- 国际栏目每条新闻保留 id、可恢复规则分和聚类 ID，旧数据未知评分不伪造。
- ticker 摘要财报输入具有稳定来源 id；运行时来源校验可引用财报。
- 已知来源 legacy 付费墙按新配置保留 metered。
- 公开论文 MSW 对私有/不存在的 id 返回 404；不以另一篇样例冒充。
- 周报反复方向最后交易日缺值时 latestRelative=null，不回填更早日期。
- AI 用量按 Asia/Singapore UTC+8 分日/月；样例中跨 UTC 日界的新闻调用与问答统一归 9 月 30 日。
