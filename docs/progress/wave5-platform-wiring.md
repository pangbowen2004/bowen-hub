## 编排决定：市场首次启动
T23 在 API 确实缺少首次计算所需的前四日摘要时，可读取精确日期的真实 T20 历史行情并以 T21 同一计算函数建立预热缓存。API 摘要始终优先；缓存必须标记实际日期、来源、成分口径与计算版本，并在 Run 中记录使用的日期。禁止手写摘要、使用未来行情或把预热缓存冒充已发布的 MarketDay。本次用户授权常规取舍按推荐处理，采用该方案推进空系统初始化。
