## 交付

- `pdf.extract_pdf`：PyMuPDF逐页排序抽文本、去掉空行、生成pages.jsonl/pages.txt/每页PNG。行号从每页1开始；`pages_text(numbered=True)`提供作者/审核/TASK用的L行号文本。输出目录由编排者注入，不写数据库/R2。重跑时清除超出新页数的旧PNG，防止残留页图。默认144dpi在paper_rules.yaml，证据行号与分辨率无关。
- `ids.identify/custom_identity/choose_identity`：只看前两页，arXiv→ACL→DOI→SSRN优先；DOI小写并替换斜杠。无编号用英文标题前6个实词、过滤配置虚词、小写短横线、最多40字符。相同编号与已知相同版本报已存在；不同版本选择未占用-v2/-v3并返回实际存在的version_of目标；重试id原样沿用。任何一方版本未知不能证明新版本，明确失败，不从存储后缀猜原文版本。
- `check.check_draft`：生成PaperDraft模型验证、必填文字非空、8个二级标题/顺序、空行正文段落与articleBlocks对应、引用存在及推断标记、页码/连续起止行号、quantities原文出现和metric数字覆盖、readerCheck七项、verified代码链接。中文错误列表。Markdown围栏内的##代码注释不当标题，纯标题不当段落。
- `excerpt.fill_source_excerpts`：从对应页的起止行连续截取，返回草稿副本；无页码的推断不保留虚构摘录。覆盖evidence.legacyAnchors=false，不设置模型出处或审核状态。由T31在校验通过后调用。
- `derive.derive_documents`：产生catalog.public/all、graph.public/all、search.public五份契约文档。公开集合先筛visibility；只读Paper，完全不接收PaperPrivate。概念小写去空白、配置同义词归并，共现每论文每概念对计一次；只连discusses/belongs_to/明确relation，不生成共享概念论文边。目标不在本集合的关系不连边，不暴露私有目标ID或关系注记。研究空间别名映射配置id，未知空间明确失败。
- `hub papers check <draft.json> [--pages <pages.jsonl>]`：默认同目录页文本，真实成功0/坏稿1。`hub papers derive`经API游标读完全部Paper再PUT五份payload（不套Document信封）；`--input <Paper数组.json> --output <目录>`为明确离线模式，不接触API。命令保留原register入口。

纯逻辑check/derive/excerpt/ids没有文件或网络IO。配置/页文件读取集中在pdf薄IO层，各commands负责API与本地文件。只改owns与根明确授权sharedEdits：hub-papers/pyproject.toml既定PyMuPDF、py/uv.lock、共享CLI测试里仅T30 check/derive改为验证help；领域另验真实退出码，没有弱化其他任务断言。新增PyMuPDF实际锁定 **1.28.2**，没有新增服务或替换技术栈。
