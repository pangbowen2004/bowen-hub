## 交付

Python hub-ai 与 TypeScript packages/ai 均包含清单/档位解析、共享提示词渲染、生成契约结构校验、传输重试最多2次（1s/2s）、结构修复1次、六个确定性校验、generatedBy、生成AiCall用量回调与L0/L1/L2可用性。Pydantic AI原生结构输出不支持时才改工具输出；OpenAI SDK自带重试关闭。TS用AI SDK6 generateObject/streamText，并只做供应商strict schema传输适配，不修改业务契约。

流式QA按提示词发送Markdown，从`[论文 p.X]`抽取页码，流末修正最终pages并返回标注；已发answer保持原样。首块之前可以重试，发送内容后不重发。消费SDK fullStream的error/abort事件，防止textStream过滤器静默丢失错误。超限及失败记录用量；供应商完全没有返回用量时计0、不编造token，不能据此断言无实际费用。

清单JSON Schema在Python加载和TS构建校验全部11个清单。TS构建把清单/提示词/LLM/规则词表/契约Schema编入忽略的生成模块，Worker不读文件；提交生成源。通用检查覆盖数量单位规范化、年份日期/季度/Item/指数排除、原文引用与行号、来源id（数字也保留）、建议删句、完整句截断、数组字符注解、页码数组/标量。原文引文只比pages/sourceText，不用待审草稿自证；领域paper_draft须由T31登记，缺登记明确失败。

实际评测入口hub_ai/evals/runner.py使用pydantic-evals Dataset/Evaluator，提供schema、六通用检查、标签、必含/禁含、balanced主观评审。评分保留修复前状态，主观评审费用计入同次EvalResult。run/compare/harvest/check-models通过T03的commands登记；PR报告不写API，每周显式写API，compare退步或不达阈值退出1。--changed只选实际能力文件变化，框架/schema变化报告0；缺用例不假绿。测试fixture.summary独立于产品能力。

new:capability真实生成清单/提示词/空的待补齐评测目录/TypeSpec模型与入口导入；默认L0，不覆盖已有文件。临时仓库已实测，不改当前产品契约。
