# T02 API 骨架与预接线

状态：已完成（待编排者审查合并）

## 交付

- Hono Workers 入口提供服务器生成的请求 ID、结构化请求日志、RFC 9457 错误与三类鉴权分流。服务令牌使用等长恒时比较，可写内部接口、可读 GET，私有写返回 403；无令牌的线上私有请求由 T40 会话占位返回 401。本地 `dev` 写入被忽略的 `.dev.vars` 普通模式变量，配置默认线上模式。
- `mise run gen` 最后从 OpenAPI 生成 80 个接口的 `routes.gen.ts`，以 operationId 接各模块 handler；未实现接口按 x-task 返回 501“未实现（任务 Txx）”。固定 auth、MCP 入口、领域 routes/service/repo/mcp 空骨架及 T41/T42 占位已接线；MCP 工具的 name、description、Zod inputSchema、handler 类型在 `src/lib/mcp.ts`，领域空工具数组由 registry 汇总。
- Drizzle schema 与两份迁移包含 docs/09 的 22 张业务表、官方通行密钥 + MCP 插件生成的 13 张鉴权表、2 张 FTS5 虚拟表。自然键、摘要列、整块 JSON 存储均按文档；FTS 触发器同步插入、更新、删除。D1/R2 的真实绑定由 T06 填写。
- 平台实现 documents 覆盖写入、runs 幂等写入与游标分页、AI 调用/评测批量写入、评测筛选读取、AI 用量 SQL 聚合。默认分页 20、最大 100；days 默认 30，UTC+8 分日/月，本月费用独立于查询窗口，预算从 config/llm.yaml 编入生成配置。直接消费生成的 Zod，数值评分字典由已合并的生成链修复提供，没有重复手写 schema。
- R2 薄封装直接传递流，指定长度时使用 FixedLengthStream；GitHub repository_dispatch 从 Worker env 获取凭据并明确返回缺配置/外部失败错误，日志不记录凭据或正文。
- `test:contract` 锁定 Schemathesis 4.28.0，每次创建独立临时 D1 和本地 Worker、探测全部契约接口，只排除返回 501 的占位，其余错误探测明确失败；支持 `--task T02` 等任务筛选。临时数据库、随机测试缓存和进程在结束时清理，不提交生成的缓存。
