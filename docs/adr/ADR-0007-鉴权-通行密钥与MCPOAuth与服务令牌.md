# ADR-0007 鉴权：通行密钥 + MCP OAuth + 服务令牌

状态：已采纳（2026-09-29）

## 背景
只有 Kevin 一个用户，但控制台和 MCP 必须安全；不想维护密码。

## 决定
Better Auth：通行密钥登录（首次注册用一次性口令），会话为 HttpOnly Cookie；Better Auth 的 MCP 插件让 API 成为 AI 客户端的 OAuth 2.1 授权服务器；计算任务用服务令牌。

## 理由
通行密钥无密码、防钓鱼，手机和电脑都能用；MCP 规范要求 OAuth，用同一套库实现最省事。

## 后果
不做注册、找回密码、多用户。丢失全部通行密钥时，用新的一次性口令重新注册。
