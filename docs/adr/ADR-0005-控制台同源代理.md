# ADR-0005 控制台同源代理

状态：已采纳（2026-09-29）

## 背景
控制台（`*.pages.dev`）和 API（`*.workers.dev`）都在公共后缀域名下，浏览器把它们当作不同站点，跨站 Cookie 会被拦；通行密钥也绑定域名。

## 决定
控制台的 Pages Function 通过 Service Binding 把 `/v1/*`、`/auth/*`、`/mcp`、`/.well-known/*` 原样转发给 API Worker。浏览器和 MCP 客户端只和控制台域名打交道。

## 理由
同源意味着第一方 Cookie、没有 CORS、通行密钥只需绑定一个域名；不买域名也能做到。

## 后果
API 的 `workers.dev` 地址只给计算任务和公开站构建使用。
