# ADR-0004 公开站静态优先，控制台为 SPA

状态：已采纳（2026-09-29）

## 背景
两个公开网址写进了求职材料，首屏速度和稳定性最重要；老站先出空壳再劫持 fetch 取数，首屏显示“0 篇”。

## 决定
公开站用 Astro 6 在构建时从公开 API 取数、生成纯静态 HTML，交互只用按需加载的 React 岛；控制台是 React 19 SPA。

## 理由
静态页面最快、最稳，不受 API 状态影响，也不消耗 Workers 额度；控制台是个人工具，交互多，SPA 更合适。

## 后果
数据更新后要重新构建公开站（由 `markets-updated`、`papers-changed` 自动触发）。
