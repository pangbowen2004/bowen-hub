# ADR-0001 多语言单仓

状态：已采纳（2026-09-29）

## 背景
三个老项目各写各的：Python 脚本、Node 前端、各自的部署。重写需要一个既适合网站与 API、又适合数据计算的组合。

## 决定
一个仓库。TypeScript 负责对外服务（三个前端、API、MCP）；Python 负责计算（行情指标、新闻管线、论文处理、评测）。两边不共享代码，只通过契约生成的类型交流。

## 理由
网站、Workers、MCP 的生态以 TypeScript 最成熟；Polars、PyMuPDF、TuShare、exchange_calendars、Pydantic AI 等计算与数据工具以 Python 最成熟。单仓让一次改动（契约 + 两端实现）在一个 PR 里完成，Agent 也能一次看到全貌。

## 后果
工具链有两套（pnpm/Turborepo 与 uv），由 mise 统一入口（`mise run …`）抹平。
