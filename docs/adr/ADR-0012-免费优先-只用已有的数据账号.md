# ADR-0012 免费优先，只用已有的数据账号

状态：已采纳（2026-09-29）

## 背景
Kevin 希望尽量免费，不再购买新的服务。

## 决定
平台用 Cloudflare 免费版与 GitHub Free；数据用 Kevin 已有的 TuShare、Alpaca、Tiingo，加上免费的 SEC、FRED、Finnhub、RSS；只有 AI 按量付费，并设月度预算提醒。

## 理由
全部需求在免费额度内可以满足（`12` 第 5 节的估算）；AI 起步用便宜的档位配置，靠评测决定是否升级。

## 后果
受免费额度约束：API 不做重计算、公开站静态化、GitHub Actions 分钟要节省。
