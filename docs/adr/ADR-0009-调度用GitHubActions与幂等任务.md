# ADR-0009 调度用 GitHub Actions + 幂等任务

状态：已采纳（2026-09-29）

## 背景
老系统依赖 Mac 开机，37 次邮件因为没网发不出去。Workers 免费版每次请求只有 10 ms CPU，跑不了计算。

## 决定
定时和按需的重活都在 GitHub Actions 上跑；每个任务幂等（先查是否已完成，写入用覆盖式 PUT），可以多设触发点，重跑不出错。

## 理由
免费、不依赖任何个人设备、有日志和重跑按钮；幂等让“GitHub 定时触发会延迟”这件事变得无害。

## 后果
触发时间有几分钟到几十分钟的误差；需要事件驱动的长流程时，升级到 Cloudflare Workflows（`12` 第 8 节）。
