# ADR-0003 五个平面与“写数据只经过 API”

状态：已采纳（2026-09-29）

## 背景
老系统里定时脚本直接写 JSON 文件、前端直接读文件，谁都能改数据，出了问题找不到源头。

## 决定
系统分为体验、服务、计算、智能、契约五个平面。数据只能经过 API 写入：计算任务用服务令牌调用 `/v1/internal/*`，前端只读公开或私有接口。

## 理由
单一写入口让校验、审计（运行记录）、导出都集中在一处；平面之间只靠契约连接，每一块都能独立开发、测试、替换。

## 后果
计算任务必须联网访问 API 才能写数据；本地开发用 `wrangler dev` 的本地 API。
