# ADR-0006 D1 为运行时事实源，R2 存大文件，每晚导出

状态：已采纳（2026-09-29）

## 背景
需要一个免费、就近、可查询的数据库，同时希望数据历史能被 git 追溯。

## 决定
结构化数据存 D1（含 FTS5 全文检索）；PDF、页文本、页图、邮件 HTML 存 R2；每晚把除鉴权表外的所有表导出到私有仓库 `bowen-hub-data`。

## 理由
D1 与 Workers 同平台、免费额度够用；大文档整块存 JSON 列，读取不解析；git 导出替代了老系统的哈希账本，既是备份也是历史。

## 后果
D1 单库 500 MB；新闻条目只保留 365 天。超出时换 Postgres（`12` 第 8 节）。
