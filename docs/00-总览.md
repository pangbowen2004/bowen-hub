## 2. 为什么推倒重写（现状核对）

**每日新闻**（`~/Desktop/Daily News`）
- 代码只有约 60 KB，结构本身不乱；问题在运行环境：任务跑在 Mac 上。147 次运行中 37 次邮件没发出去（23 次是 DNS 解析失败，也就是运行时没网；10 次是 SMTP 连接断开）。
- 138 天归档里有 34 天 AI 步骤失败，退回关键词规则模式。
- cron（写 `cron.log`）和 launchd 两套定时同时存在。
- Kevin 在 `notes.md` 里记下了三个没解决的问题：付费墙链接、主题标签不能点击跳转、中文源太少（36氪经常 0 条，虎嗅经常超时，FT 返回 403）。
- 内容以国际综合新闻为主；Kevin 现在主要做美股，需要的是和自选股相关的新闻、公告和财报。

**论文库**（`~/Documents/ChatGPT/科研`）
- 89 篇论文档案，公开站只有 19 篇；**69 篇已经读完，但状态停在“未发布”**：发布要经过 Gemini 写稿 → Codex 审核 → 审核门禁 → 回执 → 冻结快照 → 基线比对这一整条流程。
- 后端约 11,600 行 Python，其中约 6,500 行是 WorldQuant 因子挖掘（Finance Workspace、Factor Miner V2A、语料 Dry Run、Benchmark），约 1,500 行是发布审批流程，真正服务“读论文”的反而是少数。
- 每篇论文散在 10 多个文件里（R0 卡、R1 卡、理解学习包、阅读导航包、读者导读、导读文章、证据审计、看板状态……），内容相互重叠。
- 前端是一个 181 KB 的 `app.js` 加 142 KB 的 `styles.css`。公开站先给一个空壳页面，再靠劫持 `window.fetch` 去读静态 JSON，首屏会先显示“0 篇 / 正在连接”。

**市场观测台**（`~/Documents/量化/market-observatory`）
- 数据停在 **2026-08-28**，之后再没更新。
- 部署方式有过 Railway、systemd、launchd、Codex 定时任务好几套，现在一个都没在跑；公开站是 9 月 27 日手工导出的静态快照。
- 每日计算里还硬编码着 8 月 10 日一份外部 PDF 里的点位（3975 / 4004–4007 / 4070）。
- 驾驶舱 6 项核心指标里，“午后成交额同比口径变化”需要分钟数据，只有 8 月 10 日那天有外部报告里的数值，之后一直显示“不可用”。
- 周报把“证据不足（INCONCLUSIVE）”也算进了 Research Error（8 月 28 日周报：16 条 Research Error 里有 12 条其实是证据不足）。
- 公开站和论文库一样，靠劫持 `fetch` 读静态 JSON。

**共同问题**：三个项目三套写法，没有共享任何东西（配置、LLM 调用、邮件、样式、部署都各写一遍）；大量精力花在防护性流程（哈希、门禁、准入等级、审批回执）上，而不是产品本身。

## 3. 重写原则

1. **契约优先。** 所有接口和数据文档只在 TypeSpec 里定义一次，自动生成 TypeScript 和 Python 两边的类型、校验和模拟数据（`08`）。
2. **前后端完全分离，五个平面各管一件事。** 体验（网站）、服务（API）、计算（定时任务）、智能（AI 能力）、契约；写数据只有一条路：经过 API（`01`）。
3. **AI 是可替换、可评测的能力。** 每个用到模型的地方都有清单、输入输出契约、确定性校验、降级和评测；换更强的模型只改配置，由评测证明变好了（`10`）。
4. **为多个 Agent 并行开发而设计。** 任务图、路径所有权、预接线、统一命令、可执行的验收（`11`）。
5. **不依赖 Mac 开机，尽量免费。** 定时任务在 GitHub Actions；网站和 API 在 Cloudflare 免费版；只有 AI 按量付费（`12`）。
6. **公开站静态优先。** 内容在构建时写进 HTML，浏览时不请求任何接口。
7. **简单优先，不做过度防护。** 不造哈希账本、多级审批、回执门禁。要追溯看 git 和数据仓库的历史；出错就明确失败、记日志、发通知。
8. **老系统只当需求来源。** 规则、公式、阈值、提示词都已经提炼进文档和 `config/`、`prompts/`。新代码不看、不复制老代码；只在迁移时**只读**老数据。

## 4. 范围

### 4.1 要做

- **美股新闻室**：采集（新闻、SEC 公告、内部人交易、财报新闻稿、宏观与财报日程、收盘快照）→ 去重聚类 → 规则打分 → AI 加工（个股动态、要闻、财报卡片、公告要点、导语）→ 三个版次的邮件与网页版 → 反馈闭环；国际与科技栏目沿用老 Daily News 的做法，并解决 `notes.md` 里的三个问题（`02`）。
- **A 股观测台**：TuShare 收盘数据 → 全市场指标 → 行业、方向、ETF、主题 → 涨停生态 → 规则生成的状态摘要 → 次日假设与结算 → 近五日演化 → 周报 → 事件日历 → 公开站（含历史日期浏览）（`03`）。
- **论文阅读馆**：统一的论文文档模型；公开站（论文列表、单篇导读 + 证据、2D 图谱、3D 知识宇宙、研究空间、搜索）；控制台里的完整版（全部论文、笔记、掌握状态、整篇原文问答、原文页、公开开关）；自动入库流水线（上传 PDF → AI 写导读 → 校验与修订 → AI 审核 → Kevin 公开）（`04`）。
- **控制台与 MCP**：私人后台；给 AI 客户端用的 MCP 服务（`05`、`09`）。
- **数据迁移**：89 篇论文、老新闻归档、市场假设账本与事件日历全部导入；市场 8 月 31 日至今的缺口用新管线补跑（`06`）。

### 4.2 不做 / 移出

| 内容 | 去向 |
|---|---|
| 美股观测台（类似 A 股观测台的行情与指标网站）、美股行情与财务数据管线 | 本期不做。美股只做新闻和公告；收盘快照只显示涨跌幅（ADR-0011） |
| 付费数据源 | 不买。只用 Kevin 已有的账号和免费接口（ADR-0012） |
| 论文库里的 WorldQuant 因子挖掘（Finance Workspace、Factor Miner V2A、QuantML 语料 Dry Run、Gold Set、Benchmark、研究种子导出、`13-金融研究资产.yml`） | 不进新项目。老代码和数据原地保留；以后需要就另开项目 |
| 论文发布审批流（Gemini/Codex 接力、审核门禁、回执、冻结快照、发布基线、SHA-256 比对） | 用状态字段代替：审核结果记一条记录，公开是一个按钮（`04`） |
| 老论文看板的本机服务（`127.0.0.1` 上的 FastAPI） | 由控制台代替，手机上也能用 |
| 市场观测台的证据准入等级体系（`INDEPENDENT_SOURCE_VERIFIED` 等 6 级）、每个文件的 SHA-256、证据账本 | 用一张“指标说明表”代替（定义、公式、来源、是否可用） |
| 外部 PDF 手工价位、41 张参考图、2026-08-07 和 08-10 两份一次性简报 | 不迁移 |
| 需要分钟级、逐笔、席位、ETF 盘中申赎的数据 | 不做（TuShare 日频拿不到，页面也不显示“不可用”占位） |
| Railway、systemd、launchd、`cloud_service.py` 一类部署脚本 | 不做 |
| 实盘、下单、买卖建议、仓位建议、目标价 | 永远不做 |

## 7. 术语

| 术语 | 含义 |
|---|---|
| 版次 | 美股新闻室的一期：早报 `morning`、盘前简报 `premarket`、周报 `weekly`；ID 如 `morning-2026-09-30` |
| 自选股 | Kevin 关注的美股、ETF 和加密资产清单（`config/us_watchlist.yaml` 为初始值，之后在控制台维护） |
| 交易日 / `date` | A 股交易日，北京时间，格式 `YYYY-MM-DD`；美股交易日另按纽交所日历判断 |
| 上涨覆盖 `advanceShare` | 当日上涨家数 ÷ 有效样本数 |
| MA20 上方比例 `aboveMa20Share` | 收盘价高于自身 20 日均线的股票占比 |
| 触板 / 封板 / 炸板 | 最高价触及涨停价 / 收盘价等于涨停价 / 触板但收盘未封住 |
| 连板高度 `boardHeight` | 截至当日连续收盘涨停的天数 |
| 方向 | 16 个跟踪主题，每个映射到一个同花顺板块指数（`config/market_directions.yaml`） |
| 假设 / 结算 | 收盘后按规则生成的“下一交易日要验证的问题”，到期按规则判定为 确认 / 未确认 / 证据不足 |
| R0–R3 | 论文阅读深度：R0 初筛、R1 结构阅读、R2 批判精读、R3 复现 |
| 公开 / 私有 | 论文的 `visibility`：公开的进入公开站；私有的只在控制台 |
| 契约 | `contracts/` 里用 TypeSpec 写的接口与数据模型，是两种语言共同的唯一事实源 |
| 能力 | 一个用到 AI 的功能单元，如 `news.ticker_digest`（`10`） |
| 档位 | `fast` / `balanced` / `frontier`，能力按档位选模型，档位到模型的映射只在 `config/llm.yaml` |
| 自治等级 | L0 影子 / L1 草稿 / L2 自动 / L3 自主（`10` 第 6 节） |
| 波次 / 预接线 | 并行开发的组织方式（`11`） |
| 服务令牌 | 计算任务调用 API 内部接口用的密钥 `HUB_SERVICE_TOKEN` |
